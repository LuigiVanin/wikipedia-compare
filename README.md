# Wikipedia Article Compare

A simple TUI application to compare two wikipedia article

### How to install

I Recommend the creation of a virtual environment for the system:
```sh
python3 -m venv .venv

source ./.venv/bin/activate
```

To install the packages:

```sh
pip install -r requirements.txt
```


### How to run the program

```
> python3 main.py
```
